# Evidence Pack (Power Tracks Reproducibility Bundle)

Purpose: a single place pointing to reproducible artifacts, scripts, and checks so reviewers can rerun and audit. Raw Polygon ticks are not shipped; everything else is present with SHA256s. Frames are generated by the repo’s encoder (not captured on-wire); this is exploratory evidence of structural signals, not proof of intentional embedding.

## What’s Included (paths are repo-relative)
- Samples & checksums: `sample_2024-05-13..17/` (ticks, frames, signals) with `SHA256SUMS`.
- Minute bars (Polygon) for broad testing: `bars_range/` (per-day CSVs 2022-11-28..2024-11-26).
- Reports:
  - Predictiveness: `reports/predictiveness.json`, selector lift `reports/selector.json`.
  - TISA (base): `reports/tisa_*.json`, summary `reports/tisa_summary.json`, plots `reports/plots/tisa_distance.png`, `reports/plots/tisa_rmse.png`.
  - Extended windows (z-RMSE, DTW, shuffled baselines): `reports/tisa_extended_*.json`, plots `reports/plots/tisa_extended_*.png`.
  - Overlays: decoded vs future bars per window/day in `reports/plots/overlays/`.
- Scripts:
  - Rebuild/verify: `scripts/rebuild_day.py`, `scripts/verify_reproducibility.py`.
  - Fetch bars: `scripts/fetch_minute_bars.py`, `scripts/fetch_minute_bars_range.py`.
  - Features/predictiveness: `scripts/build_features.py`, `scripts/eval_predictiveness.py`.
  - TISA: `scripts/tisa_validate.py`, extended: `scripts/tisa_extended.py`.
  - Plotting: `scripts/plot_reports.py`, `scripts/plot_tisa_extended.py`, `scripts/plot_tisa_overlays.py`.

## How to Reproduce Core Claims
1) Verify samples (ticks → frames → signals → SHA256):
   - For each day: `python scripts/rebuild_day.py --date 2024-05-13` (needs `POLYGON_API_KEY`), then `python scripts/verify_reproducibility.py --sample-dir sample_2024-05-13 --manifest sample_2024-05-13/MANIFEST.json --sha256 sample_2024-05-13/SHA256SUMS`.
2) Predictiveness:
   - Build features (if needed): see `scripts/build_features.py` (inputs: signals + bars).
   - Evaluate: `python scripts/eval_predictiveness.py --features features/*.csv --output reports/predictiveness.json`.
   - Plots: `reports/plots/predictiveness_hit_rate.png`.
3) TISA base:
   - Per day: `python scripts/tisa_validate.py --signals sample_2024-05-13/signals/price_paths.csv --bars-dir bars_range --symbol GME --date 2024-05-13 --horizons 1 4 7 30 90 180 --scales 0.5 0.75 1.0 1.25 2.0 4.0 --output reports/tisa_2024-05-13.json`.
   - Summary plots: `reports/plots/tisa_distance.png`, `reports/plots/tisa_rmse.png`.
4) TISA extended (windowed, z-RMSE/DTW, shuffled baselines):
   - Per day: `python scripts/tisa_extended.py --signals sample_2024-05-13/signals/price_paths.csv --bars-dir bars_range --symbol GME --date 2024-05-13 --windows 0-30 60-70 70-80 80-90 150-180 --scales 0.5 0.75 1.0 1.25 2.0 4.0 --output reports/tisa_extended_2024-05-13.json`.
   - Plots: `reports/plots/tisa_extended_*.png` (z-RMSE vs scale per window).
   - Overlays: `reports/plots/overlays/<date>_<window>.png` (decoded vs future z-scored shapes using best z-RMSE scale).

## Notes / Limitations
- No on-wire packet capture: frames are generated via the repo encoder from Polygon ticks. Interpret as exploratory structure, not proof of intentional embedding.
- Statistical strength is exploratory. Shuffled baselines are included; for formal significance, run multiple permutations and report p-values (scripts can be extended; current configs include small shuffle samples).
- Scope: GME 2024-05-13..17 deep dive. Additional dates/symbols can be added by rerunning the scripts.

## Suggested Reviewer Flow
1) Check SHA256SUMS for samples to confirm integrity.
2) Rebuild one day end-to-end with your `POLYGON_API_KEY`.
3) Inspect predictiveness report/plot; compare against shuffled baselines.
4) Inspect TISA/TISA-extended reports and overlays for windows 60–70/70–80d where lift is strongest vs shuffled.

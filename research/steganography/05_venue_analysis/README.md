# Venue Analysis

Phase 5: Analyzing trading patterns by venue (EDGX, OTC, standard exchanges).

## Analysis Methods

1. **Venue-specific LSB patterns** - Do certain venues show more anomalies?
2. **Cross-venue timing** - Timing between venue transitions
3. **Venue sequence patterns** - Encoding via venue switching
4. **Price divergence** - Venue-specific price discrepancies

```bash
python venue_analysis.py
```
